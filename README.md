# 🏸 バドミントン大会運営アプリ

大会要項の作成 → 参加申込 → 組み合わせ → タイムテーブル → 当日の進行・結果入力 → 結果集計 までを一つで行えるWebアプリです。
GitHub Pages で動作し、インストールやサーバー契約は不要です。

## できること

| 機能 | 内容 |
|---|---|
| 大会要項 | 「関係者各位／発行日・発行者／○○大会 実施要項／記／1 主催…」の実施要項様式。和暦表記、申込先の枠（TEL・E-Mail・LINE・QRコード画像）、印刷・PDF保存 |
| 種目（クラス） | シングルス・ダブルス・**団体戦**。種目ごとに **トーナメント / リーグ戦 / 予選リーグ→決勝トーナメント** を選択（同じ大会内で混在可）。ゲーム数・点数・定員・使用コート・3位決定戦 |
| 申込 | 手入力、CSV取込（Googleフォーム・Excelの出力に対応）、**参加者によるWeb申込**（Google連携時） |
| 団体戦 | チーム名＋メンバー表で申込。1対戦の内訳（例：第1ダブルス・第2ダブルス・シングルス）ごとにスコアと出場選手を入力し、勝ち数で勝敗を自動判定。リーグ順位は勝数→得失マッチ率→ゲーム率→得点率 |
| 組み合わせ | シード配置・不戦（BYE）自動配置・**同一所属を離して自動抽選**。グループ分け、手動入替え、順位の手動指定 |
| タイムテーブル | コート数・1試合の時間・最低休憩から自動作成。複数種目に出る選手も重ならないよう配置。遅れたときは「未終了の試合だけ組み直す」 |
| 進行・結果入力 | コートごとの「コール」→「結果入力」。勝ち上がり・リーグ順位（勝数→直接対決→得失ゲーム率→得失点率）を自動計算 |
| 結果 | 入賞者一覧、全試合結果CSV、印刷 |
| 公開ページ | 要項・組み合わせ・タイムテーブル・速報をスマホで閲覧（1分ごと自動更新）。連絡先は公開されません |

## 使い方

1. 公開URL（GitHub Pages）を開く
2. 「大会要項」→「種目」→「申込」→「組み合わせ」→「タイムテーブル」→「進行・結果入力」の順に進める
3. まず試すときは「デモデータを読み込む」

データは**使っているブラウザに自動保存**されます。別のパソコンで続ける場合は「設定・連携」から JSON に書き出し／読み込み、またはクラウド保存を使ってください。

## Web申込・結果公開を使う場合（Google連携・無料）

1. Googleドライブで新しいスプレッドシートを作成
2. 「拡張機能」→「Apps Script」に [`gas/Code.gs`](gas/Code.gs) を貼り付け
3. `ADMIN_KEY = 'change-me'` を自分だけが知る文字列に変更して保存
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」
5. 表示されたURLと管理キーをアプリの「設定・連携」に入力 →「接続テスト」→「大会情報を公開」
6. 表示される **申込ページURL** を参加者に案内。申込はスプレッドシートの「申込」シートにも記録されます
7. 「申込」タブの「オンライン申込を取り込む」でアプリに反映

## 構成

```
index.html     管理画面
apply.html     参加者用 申込ページ
view.html      公開ページ（要項・組み合わせ・速報）
js/core.js     組み合わせ・順位・タイムテーブルの計算
js/render.js   ドロー表・リーグ表・タイムテーブルの描画
js/app.js      管理画面
gas/Code.gs    Google Apps Script（申込受付・公開データ保存）
```

ビルド不要の HTML / JavaScript のみで作られています。
